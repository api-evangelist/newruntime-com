New Runtime is an atlas of agent-shaped software, tracking systems, signals, and shifts that reshape software as agents become first‑class participants in work, products, and organizations. It provides a curated map of emerging agent‑centric technologies, offering insights, data feeds, and an open API for developers to integrate agent‑based intelligence into their applications.

**Areas:** AI · Agents · Data · Atlas · Software

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for New Runtime: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
